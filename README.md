# Optimum Contributor Hub

Unofficial community contributor card prototype. Built for GitHub Pages.

## Publish

1. Create a public GitHub repository named `optimum-contributor-hub`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` directory to the repository root.
3. Go to **Settings → Pages → Build and deployment**. Select **Deploy from a branch**, `main`, and `/ (root)`, then save.
4. Open `https://YOUR-USERNAME.github.io/optimum-contributor-hub/` after deployment completes.

## Important

This prototype uses fictional data and does not connect to Discord. OAuth, verified role lookup, contribution data, and real rankings require additional development and authorization. The X button opens a prefilled X post; it cannot attach the card image automatically. The Download button uses html2canvas from a CDN and needs an internet connection. No API secrets should ever be committed to GitHub Pages.
